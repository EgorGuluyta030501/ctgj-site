# CTGJ — сайт торгово-логистической компании (Китай)

Пользователь общается по-русски; все ответы, комментарии в коде и тексты коммитов — на русском.

## Правила работы (важно)
- **Не публиковать без команды.** Идёт этап правок: изменения делаем только локально, `git push` не выполнять — push в `main` сразу публикует демо на GitHub Pages (workflow `.github/workflows/pages.yml`). Локальные коммиты можно.
- После каждой правки — проверить в браузере (скриншоты через CDP, см. ниже) и при необходимости положить скриншоты в `screens/` (папка в .gitignore) со ссылками в ответе.
- При изменении CSS/JS повышать метку версии `?v=…` у ссылок в `public/index.html` (сейчас `20261013o`): на GitHub Pages файлы кешируются.

## Устройство
- `server.js` — Node без фреймворков: статика (Range для видео, HTML/CSS/JS с `no-cache` + 304), API заявок и админки, лимиты, Telegram-уведомления (`TG_BOT_TOKEN`, `TG_CHAT_ID`).
- `db.js` — PostgreSQL (`pg`). Без `DATABASE_URL` поднимает локальный embedded-postgres в `data/pg` (порт 5433, UTF-8, `C.UTF-8`), восстанавливается после аварии. Схема создаётся при старте.
- `public/index.html` — одна страница: заставка с драконом → hero с видео → «О компании» (преимущества, «Как мы работаем») → «Услуги» (фонари-шары, переворот) → «Проекты» (карусель, клик открывает страницу проекта `#project-N`) → «Партнёры» → «Контакты» → подвал. Боковой конверт «Получить КП» открывает форму.
- `public/js/i18n.js` — все тексты RU/EN/ZH (ключи `data-i18n`). Пользователь иногда правит тексты сам — не перетирать его правки.
- `public/js/main.js` — языки, тема (тёмная/светлая, `data-theme` на `<html>`), заставка, видео, скролл, карусель проектов, страница проекта (`projectHtml`, фото `P_PHOTOS`), партнёры, формы.
- `public/js/dragon.js` — дракон и ночная сцена на canvas (заставка ~4 с). Дракон золотой «как на видео заказчика»: светящиеся глаза, бирюзовый «воротник», тёмные рога.
- `public/js/ambient.js` — круглые красные фонарики, всплывающие по полям секций.
- `public/css/style.css` — переменные темы в `:root` и `:root[data-theme='light']`; hero, заставка и шапка над видео всегда тёмные.
- `public/video/` — `hero.mp4` / `hero-mobile.mp4` / `hero-poster.jpg` (4 дневных города + порт, фура, поезд, самолёт).
- `public/img/projects/p1..p5.jpg` — фото проектов (p1 и p5 — CC BY-SA, подпись автора выводится на фото).
- `public/партнеры/` — логотипы партнёров `NN-name.png` (порядок по имени). Список собирает `scripts/partners.js`: сервер — на лету, GitHub Actions — при сборке. Исходники от заказчика лежат в `партнеры/` в корне.

## Ловушки
- **`String.prototype.replace` и `$$`**: при вставке кода через `.replace(a, b)` в строке замены `$$` превращается в `$` (уже ломало `$$(...)` дважды). Вставлять кусками через `slice` или Edit-инструментом, после вставки грепать `$('…').forEach`.
- Bash в Windows портит кириллицу в аргументах curl/JSON — тела запросов писать в файл в UTF-8.
- Длинные node-скрипты с кавычками не передавать через heredoc в bash — писать в файл в scratchpad и запускать.
- Скриншоты: `node tools/cdp.js сценарий.json` (headless Chrome по DevTools Protocol; шаги goto/eval/print/mouse/shot, пример — `tools/example.json`). Сценарии и скриншоты удобно класть в scratchpad, скриншоты для пользователя — в `screens/`. Для мобильной версии: `"width":390,"height":844,"mobile":true`.
- ffmpeg: `C:/Users/guluy/AppData/Roaming/Python/Python313/site-packages/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe` (обработка видео, логотипов, склейка скриншотов). PIL/ImageMagick нет.
- Локальный сервер в фоне живёт максимум 2 ч и умирает вместе с разговором — в начале работы проверить `curl http://localhost:3000` и при необходимости запустить `node server.js` в фоне.
